What's New

Every update,
documented.

nutrx ships fast and improves constantly. Here's everything that's changed, version by version.

v1.4 24 Mar 2026 Current

Features

Home screen widgets

Three sizes (small, medium, large) showing your daily nutrient progress with interactive + buttons to log directly from your home screen.

Lock screen widgets

Circular ring gauge and inline text widget showing your daily completion count at a glance — no unlock needed.

Shared data via App Groups

Widgets read from the same SwiftData store as the main app via a shared container. Existing data migrates automatically on first launch.

Improvements

Instant widget refresh

Widgets update immediately after logging (via + button or in-app) and on every app foreground.

Date in navigation bar

The Today screen now shows the current date (e.g. "Tuesday, 24 March") instead of a static title.

v1.3 23 Mar 2026

Improvements

Completion count in group headers

Collapsed and expanded group headers now show how many nutrients have hit their daily target (e.g. "2 / 5").

Inline group creation

Create a new group directly from the nutrient form's group picker — no need to leave the screen.

Haptic feedback

Subtle haptic feedback on +/− buttons for a more tactile logging experience.

Tighter group spacing

Reduced section spacing between groups on the Today screen for a more compact layout.

Notes in reminders

Nutrient reminders now include the nutrient's note as the notification body when one is set.

Fixes

Reminders not firing

Fixed nutrient reminders not triggering due to an async race condition in notification scheduling.

Comma decimal separator

Fixed decimal input not working on devices using comma separators (e.g. entering "0,5" as a step value).

Number display precision

Fixed values truncating to 1 decimal place — now shows up to 2 (e.g. "0.25").

v1.2 21 Mar 2026

Features

Nutrient grouping

Organise nutrients into named groups (e.g. Vitamins, Supplements). Groups are collapsible on both Today and My Nutrients, with an aggregate progress bar when collapsed.

Manage Groups

New screen in Settings for creating, renaming, reordering, and deleting groups. A default "General" group is created automatically.

Move to Group

Long-press any nutrient on Today or My Nutrients to quickly move it to a different group.

Group picker on create

When adding a nutrient, a group picker lets you assign it to a group right away (defaults to General).

v1.1 21 Mar 2026

Features

Per-nutrient dose reminders

Set multiple daily reminders per nutrient (e.g. Aspirin at 9 AM, noon, and 8 PM). Smart suppression cancels upcoming reminders after you log intake.

Nutrient notes

Optional free-form text field on each nutrient. Shown as a muted line below the nutrient name on the Today card.

Monthly section headers in History

Day entries grouped under sticky month headers (e.g. "March, 2026") for easier navigation.

Swipe actions on Today

Swipe right to add an exact amount, swipe left to edit a nutrient — right from the Today screen.

Custom amount notes

Add an optional note when logging an exact amount. Notes are visible in the History intake detail.

Settings page

New Settings screen with a Notifications toggle and About section. Access it from the profile menu.

Daily check-in reminder

Opt-in local notification at noon if you haven't logged anything that day. Smart scheduling adjusts based on your activity.

Notification prompt banner

Dismissible banner on the Today screen prompting you to enable the daily reminder. Shown once after onboarding.

Fixes

Migration crash fix

Fixed a SwiftData migration crash when the notification banner preference was added without a property-level default.

Notification permission prompt

Fixed the permission prompt being swallowed when triggered from within a sheet.

Stale reminder list

Fixed reminder list and count not refreshing after adding a new reminder.

"Add Reminder" button visibility

Fixed the button being hidden behind the date picker by switching to a compact picker layout.

v1.0 20 Mar 2026

Features

Onboarding

A two-step setup flow — personal info first, then your first nutrient. The app is never empty on day one.

User-defined nutrients

No preset list. Create any nutrient with a custom name, unit, step size, and daily target.

Today, My Nutrients & History tabs

The core three-tab layout. Log intake with +/−, manage your list, and browse every past day.

Fully offline & private

All data stored locally via SwiftData. No accounts, no servers, no telemetry — ever.
